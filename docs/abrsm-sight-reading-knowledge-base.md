# ABRSM 視奏知識庫

這份文件收集**生成器與 App 需要據以決策的 ABRSM 視奏知識**：評分怎麼給、考官在聽什麼、30 秒準備時間該做什麼、以及各級數的音樂語法特徵。

## 1. 評分：考官到底在給什麼分

**配分 21 / 150（14%）**，與音階琶音同分量。✅

評分向度（四項）✅：

| 向度 | 內容 |
|---|---|
| 音高正確 | 音符、調號、臨時記號 |
| 節奏正確 | 音值、拍號、拍點 |
| **連貫性 / 流暢度** | 不停頓、維持脈動 |
| 音樂細節 | 力度、articulation、速度術語所指的性格 |

### 最重要的一條：不要回頭改

> 錯了就繼續走。停下來修正會打斷節奏流動，**而且會被算成另一個錯誤**。✅

這條在教學資料裡反覆出現，實務上的意涵是：**維持脈動的價值高於音符正確**。彈錯音但拍子穩，比彈對音但停頓兩次拿得高。

考官也不期待完美：「考官很少聽到完美的視奏，但他們永遠會欣賞正確的方法，以及隨級數逐漸提升的調性與音值意識。」✅

### 對 App 的意涵

- 倒數結束後的提示語應該強調「不間斷彈完」，而不是「彈正確」——目前 App 就是這樣寫的
- 「播放正確版本」是拿來**事後比對**的，不該在準備時間內提供
- 未來若做自我評分，權重應該是：脈動穩定 > 節奏 > 音高 > 表情

## 2. 30 秒準備時間：該做什麼

考生有**半分鐘**看譜，可以試彈全部或任何片段。✅ 標準檢查順序：

1. **調號** — 是什麼調？有哪幾個升降記號？找出主音
2. **拍號** — 幾拍子？複拍子要以「大拍」感覺（6/8 是兩大拍，不是六小拍）✅
3. **速度／性格術語** — Andante？Allegretto？決定要用多慢的速度起頭
4. **把位** — 兩手各自從哪個位置開始，中途有沒有換把位
5. **掃描難點** — 臨時記號、節奏最密的一小節、最大的跳進
6. **心裡數一小節** — 建立脈動再開始

實務建議：**用最難的那一小節決定速度**，而不是用第一小節。✅

App 在倒數期間顯示的正是這份清單。

## 3. 級數語法特徵（生成器的實作依據）

以下是規則表沒寫、但直接影響「像不像考題」的部分。標 ❗ 者為我從範例集觀察與音樂常識推得，非官方文字。

### 3.1 樂句結構 ❗

ABRSM 視奏題幾乎都是**方整的樂句**：4 小節、6 小節、8 小節，極少奇數。第 1–2 小節的動機通常在第 3–4 小節以「原樣重複／模進／同節奏異音高」的方式再現。生成器據此在節奏層做動機重用。

結尾一律收在主音，倒數第二小節多為屬和弦（V–I）。

### 3.2 和聲骨架 ❗

雖然是單純的旋律加伴奏，但底下都有清楚的和聲進行。這是生成器最重要的一課：

- **強拍落和弦音**，弱拍才允許級進的非和弦音
- **非和弦音必須級進進入、級進離開**——跳進到非和弦音就是錯音，不是經過音
- 兩手不能各自獨立生成。低音先寫，旋律要**對著實際發聲的低音**檢查垂直音程

實測：兩手獨立生成時，約 **18%** 的同時發聲音程是二度／七度／三全音；加上垂直檢查後降到 **1–2%**，剩下的都是弱拍經過音。

### 3.3 織體演進

| 級數 | 織體 |
|---|---|
| 1 ✅ | 雙手輪流，絕不同時發聲；固定五指位置 |
| 2 ✅ | 雙手同時，仍在五指位置，多為音對音或旋律配長音低音 |
| 3 ✅ | 離開五指位置，出現兩音和弦 |
| 4 ✅ | 兩手節奏開始獨立 |
| 5 ⚠️ | 四部和弦（每手最多兩音）、踏板 |
| 6–8 ❗ | 內聲部、多聲部、跨譜表 |

### 3.4 小調的處理 ❗

- 升高的第七級（導音）是調號外的臨時記號，但**不算參數表意義下的「半音」**——Grade 1–3 雖標示不含半音，a 小調的 G♯ 仍然合法
- 升高的第七級旁邊不可出現自然的第六級，否則形成**增二度**，ABRSM 不會這樣寫
- 兩手不能一手用升七級、另一手用自然七級同時發聲，那是**假關係（false relation）**，是生成器能產生的最刺耳結果

生成器對這三點都有對應處理與回歸測試。

另外，**g#／d#／a# 小調不會出現**：它們的導音需要重升記號（F##、C##），這個程度的視奏不會這樣寫。

### 3.4b 記譜合法性（已測試強制）

除了參數表之外，以下是「不管哪一級都不能違反」的記譜規則，各有回歸測試：

| 規則 | 說明 |
|---|---|
| 音域 | 所有音符落在 88 鍵之內（MIDI 21–108） |
| 重升降記號 | 完全不出現 |
| 調外臨時記號 | 只在該級允許半音時出現；小調升七級不算 |
| 旋律增二度 | 不出現（升七級被自然六級級進接觸時取消升高） |
| 和弦拼法 | 加音在主音下方一個八度內，且不構成二度／七度／三全音 |
| 連音符 | 必須是完整的組，且總長剛好填滿其參考音值 |
| 連桿 | 在四分音符或附點四分音符為拍的拍號中不跨拍 |
| 臨時記號列印 | 只在與調號不同時列印，一致不多不少 |
| 整小節休止 | 只在該手整小節不發聲時使用 |
| 聲部交叉 | 右手不低於左手同時發聲的最高音 |

### 3.5 難度是「密度」，不只是「詞彙」❗

高級數不是只有「多了十六分音符這個選項」，而是**實際用得更密**。單看規則表會做出「Grade 8 的詞彙很廣但每小節只有 6 個音」的題目，讀起來跟 Grade 3 一樣簡單。

規則表因此有一個 `generatorHints.activity`（0–1），控制節奏細胞抽取時偏長音或偏短音：

| Grade | activity | 每手每拍音符 | 每小節音符（雙手） | 小節數 |
|---|---|---|---|---|
| 1 | 0.20 | 0.32 | 2.0 | 4.4 |
| 2 | 0.28 | 0.75 | 4.7 | 5.8 |
| 3 | 0.36 | 1.02 | 6.6 | 7.5 |
| 4 | 0.42 | 1.40 | 8.8 | 7.7 |
| 5 | 0.50 | 1.55 | 9.8 | 10.3 |
| 6 | 0.58 | 1.76 | 10.7 | 12.3 |
| 7 | 0.66 | 1.90 | 11.6 | 14.3 |
| 8 | 0.72 | 2.00 | 12.4 | 14.3 |

（每 300 題實測。Grade 1 的數字偏低是因為雙手輪流，任一時刻只有一隻手在響。複拍子的「每拍」是附點四分音符，所以 G4 以上的數字含有複拍子帶來的墊高。）

三連音、四個十六分音符這類是**點綴而非常態**：實測約 5% 的小節含三連音。

### 3.6 拍號不是等機率 ❗

實際考題以 4/4、3/4、2/4 為主，6/8 引入後常見，其餘（3/8、2/2、9/8、12/8、5/4、7/8）都是偶爾出現。等機率抽取會讓 Grade 6–8 最常出現 12/8 和 9/8，明顯不像真的考卷。規則表因此有 `exam.timeSignatureWeights`：

| 拍號 | 權重 | | 拍號 | 權重 |
|---|---|---|---|---|
| 4/4 | 10 | | 3/8 | 2 |
| 3/4 | 8 | | 2/2 | 1.5 |
| 2/4 | 7 | | 9/8、12/8 | 1 |
| 6/8 | 4 | | 5/4、7/8 | 0.6 / 0.4 |

實測分布：4/4 約 30–43%、3/4 約 24–35%、2/4 約 16–22%、6/8 約 15%（G4 起）。

| 項目 | 說法 A | 說法 B | 目前採用 |
